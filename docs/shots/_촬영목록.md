# Inspector 촬영 목록 — 나중에 한 번에 자동으로 찍는다

교재에서 컴포넌트를 소개할 때는 **에디터 Inspector 화면을 찍어서** 그 안의 값들을 하나씩 설명한다.
글로만 쓰면 `Constraints` 같은 건 어디를 체크해야 하는지 알 수가 없다.

---

## ⚠️ 촬영 전에 반드시 읽을 것

`InternalEditorUtility.ReadScreenPixel` 은 이름과 달리 **Unity 창이 아니라 데스크톱 전체 픽셀을 읽는다.**
Unity 가 맨 앞에 없으면 그 자리에 있는 것이 그대로 찍힌다.

**실제로 한 번 사고가 났다.** 시험 촬영에서 브라우저 화면이 찍혔고 즉시 삭제했다.

### 안전 절차 — 매 촬영마다

1. **사장님께 먼저 알리고 시작한다.** 화면에 다른 걸 띄워두지 않은 상태여야 한다
2. Unity 를 맨 앞으로 올린다
3. **포그라운드가 Unity 인지 확인한다. 아니면 즉시 중단**한다
4. Inspector 창 영역만 읽는다
5. 찍은 뒤 **반드시 열어서 확인**한다. Unity 화면이 아니면 즉시 삭제하고 중단

### 좌표 변환 (이 PC 기준)

```
화면 해상도   1920 x 1080  (물리 픽셀)
Unity 창 좌표 1536 기준     (논리 포인트)
DPI 배율      1.25

물리픽셀 = 논리좌표 x 1.25
ReadScreenPixel 은 좌하단 원점 → glY = 1080 - (물리y + 물리높이)
```

떠 있는 Inspector 를 만들어 크게 띄우면 도킹된 269px 보다 훨씬 읽기 좋다.

```csharp
var t = typeof(UnityEditor.Editor).Assembly.GetType("UnityEditor.InspectorWindow");
var win = ScriptableObject.CreateInstance(t) as EditorWindow;
win.ShowUtility();
win.position = new Rect(120, 90, 430, 760);
```

## 찍을 목록

각 항목은 **해당 컴포넌트만 펼치고 나머지는 접은 상태**로 찍는다.

| 파일 | 대상 | 컴포넌트 | 챕터 | 무엇을 설명하려고 |
|---|---|---|---|---|
| `cp-02/insp-transform.png` | Bird | Transform | cp-02 | Position / Rotation / Scale 세 줄의 뜻 |
| `cp-02/insp-camera.png` | Main Camera | Camera | cp-02 | Projection, Size, Background Type, Background 색 |
| `cp-03/insp-material.png` | BirdMaterial | Material | cp-03 | Shader 줄, Surface Inputs > Base Map 색칸 |
| `cp-03/insp-renderer.png` | Bird | Mesh Renderer | cp-03 | Materials 배열에 머티리얼이 들어가는 자리 |
| `cp-04/insp-script.png` | Bird | Bird Move (Script) | cp-04 | 스크립트가 컴포넌트로 붙은 모습, Script 칸 |
| `cp-07/insp-public.png` | Bird | Bird Move (Script) | cp-07 | `public` 필드가 Fall Speed 칸으로 노출된 모습 |
| **`cp-10/insp-rigidbody.png`** | **Bird** | **Rigidbody** | **cp-10** | **Mass / Use Gravity / Interpolate / Constraints 체크박스 6개** ← 우선순위 높음 |
| `cp-10/insp-collider.png` | Bird | Box Collider | cp-10 | Is Trigger, Center, Size (cp-19·20 에서 다시 쓴다) |

**cp-10 의 Rigidbody 가 가장 급하다.** `Constraints` 는 접혀 있는 경우가 많아
펼친 상태로 찍어야 하고, Freeze Position 의 Z 와 Freeze Rotation 의 X·Y·Z 를
체크한 모습이 보여야 한다.

## 찍은 뒤 교재에 넣는 방식

스크린샷 위에 **번호 마커를 CSS 로 얹고**, 아래 표에서 번호별로 설명한다.
이미지에 글씨를 굽지 않는다 — 나중에 설명을 고칠 때 다시 찍어야 하기 때문이다.

```html
<div class="figure">
  <div class="shot">
    <img src="../shots/cp-10/insp-rigidbody.png" alt="Rigidbody 컴포넌트">
    <span class="pin" style="left:62%; top:18%">1</span>
    <span class="pin" style="left:62%; top:31%">2</span>
  </div>
  <div class="figure__cap">그림 10-2 · Rigidbody 컴포넌트</div>
</div>
<div class="table"> ... 번호별 설명 ... </div>
```

DESIGN.md 규칙대로 **그림은 다크 패널(`.figure`) 안**에 넣는다.

---

## 아직 안 찍은 곳은 어떻게 두나

챕터에는 **HTML 로 재현한 Inspector** 를 먼저 넣어두고, 촬영이 끝나면 교체한다.
재현본은 확대해도 안 깨지고 다크/라이트에 대응하지만, **"진짜 이렇게 생겼다" 는
정보는 주지 못한다.** 그래서 결국 실물로 바꾼다.
