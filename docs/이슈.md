# 이슈 기록

레퍼런스 구현을 만들면서 발견한 **syllabus·배포 패키지 자체의 문제**를 남긴다.
교재를 쓰기 전에 반영해야 할 것들이다. (구현 중 내가 막힌 것은 `docs/steps/cp-XX.md` 의 "내가 실제로 막힌 곳"에 적는다)

---

## #1 · Active Input Handling 이 syllabus와 어긋나 있다 — **높음**

**발견 시점**: Phase 0 착수 전 사전 조사

```
ProjectSettings/ProjectSettings.asset
  activeInputHandler: 1        ← Input System Package (New) 전용
```

**문제**
- `syllabus.md` cp-00 체크는 **`Both`** 를 요구한다
- cp-08 개념은 `Input.GetKeyDown(KeyCode.Space)` — **구 Input Manager API** 다
- New 전용 상태에서 이 API를 호출하면 런타임에 `InvalidOperationException` 이 난다
  (`You are trying to read Input using the UnityEngine.Input class, but you have switched active Input handling to Input System package in Player Settings.`)

**영향 범위**
이 프로젝트만의 문제가 아니다. Unity 6 URP 3D 템플릿의 **기본값이 New 전용**이므로, 학생이 cp-00에서 `Both` 로 바꾸는 걸 놓치면 **8번 항목까지 진도를 나간 뒤에야 터진다.** 그 시점엔 원인이 코드에 있다고 착각하기 쉽다.

**대응**
- 레퍼런스: Phase 0에서 `Both` 로 변경
- 교재: cp-00 시연 절차에 **"Active Input Handling 을 Both 로 바꾼다"를 눈에 띄게 넣는다.** 안 바꿨을 때 나오는 에러 메시지 전문을 cp-08 "흔한 막힘"에 실어둔다

## #2 · `guide.md` 가 존재하지 않는데 두 곳에서 참조된다 — **중간**

- `syllabus.md` 주석: *"시연 절차, 먼저 겪게 할 것, 흔한 막힘, 분량은 guide.md 에 있다"*
- `unity-tutor-package/package/README.md`: *"수업 준비는 별도 저장소의 guide.md 를 본다"*
- `.claude/settings.json` 은 `guide.md` 의 Read/Edit/Write 를 전부 deny 하고 있다 (존재하지 않는 파일에 대해)

이번 작업의 최종 산출물이 바로 이 파일이므로, **완성 후 파일명·배치 위치를 확정해야 한다.** deny가 걸려 있어 튜터가 읽지 못하는 것은 의도된 동작이다.

---

## #3 · 템플릿 잔재가 cp-00 체크 기준과 맞지 않는다 — **낮음**

cp-00 체크: *"`Assets` 아래 폴더 다섯 개가 보인다"*

현재 `Assets/` 아래:
```
Audio  Editor  Materials  Prefabs  Scenes  Scripts  Settings  TutorialInfo
```
→ 여덟 개. `Editor`(튜터의 ErrorCapture), `Settings`(URP 필수)는 지울 수 없고, `TutorialInfo`·`Readme.asset`·`InputSystem_Actions.inputactions`·`Scripts/Test.cs` 는 URP 템플릿 잔재다.

**교재의 "다섯 개"가 무엇을 가리키는지 확정이 필요하다.** (`Audio / Materials / Prefabs / Scenes / Scripts` 로 보인다)
