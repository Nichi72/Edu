# 수업 기록기 — 유니티와 코드가 어떻게 바뀌는지 시각과 함께 남긴다

수업을 영상으로 찍는 동안, Unity 안에서 일어난 일을 기록기가 같은 시각으로 적는다.
영상은 "왜 그랬나, 뭐라고 말했나"를 담고, 기록기는 "무엇이 언제 바뀌었나"를 담는다.
둘을 시각으로 이어 교재 재료로 쓴다.

## 구성

| 것 | 위치 | 역할 |
|---|---|---|
| 기록기 | `Assets/Editor/ChangeRecorder/` (파일 2개) | Unity 메뉴 「기록」. 이 폴더만 복사하면 다른 프로젝트에서도 돈다 |
| 보고서 | `tools/record-report.py` | 기록 폴더 → `report.md` 한 장 |
| 기록 | `recordings/<날짜_시각>/` | 세션 하나. git 에는 안 들어간다 (`[Rr]ecordings/` 무시) |

## 수업 날 하는 일

1. Unity 메뉴 **기록 ▸ 창 열기** → 창의 **시작**. 바로 이어 OBS 녹화 시작.
   첫 마커를 찍으며 "싱크"라고 말해 두면 영상과 맞추기 쉽다.
2. 평소대로 수업한다. 저장(Ctrl+S)도 평소대로. 커밋은 안 해도 된다.
3. 설명으로 들어가기 전, 학생을 멈추는 지점마다 **Ctrl+Shift+M** (마커). 글은 안 써도 된다.
   창의 입력칸에 한 줄 적고 Enter 를 쳐도 된다.
4. 끝나면 창의 **끝**.

수업 중에 Unity 가 스크립트를 컴파일하거나 Play 에 들어가도 기록은 이어진다.
끝을 안 누르고 Unity 를 닫아도, 다시 열면 이어서 기록한다 (3시간 넘게 비어 있으면 자동으로 끝난다).

## 다른 PC 에서 찍을 때

1. `Assets/Editor/ChangeRecorder/` 폴더를 그 프로젝트의 `Assets/Editor/` 아래에 복사한다.
2. 위 순서대로 찍는다.
3. 끝난 뒤 그 프로젝트의 `recordings/<날짜_시각>/` 폴더를 통째로 이 레포의 `recordings/` 로 가져온다.
4. 여기서 `python tools/record-report.py` 를 치면 가장 최근 세션의 보고서가 나온다.

## 잡는 것

- **에디터 조작** — 오브젝트 생성·삭제·이름 변경·부모 변경, 컴포넌트 추가·제거, Inspector 값 변화(이전 → 이후),
  머티리얼 값 변화, 에셋 생성·삭제·이동, 씬 저장, 프리팹 편집 모드, 어떤 오브젝트를 클릭했는지
- **코드** — `.cs` 가 저장될 때마다 사본. 보고서에는 직전 저장과의 diff 가 붙는다
- **실행** — Play / Stop / Pause / Step, 컴파일과 에러(파일:줄), Console 로그(같은 메시지는 횟수로 압축)
- **마커** — 수업에서 멈춘 지점

## 못 잡는 것

말, 손으로 가리킨 곳, 메뉴를 열었다 닫은 것, Scene 뷰 카메라 이동. 이건 영상에만 있다.

## 보고서 읽는 법

`report.md` 는 마커로 절이 나뉜 타임라인이다. 각 줄의 `hh:mm:ss` 는 기록 시작 후 경과 시간,
괄호는 벽시계 시각이다. 영상에서 그 시각을 찾으면 그때 한 말이 나온다.

원본은 `events.jsonl`(한 줄이 사건 하나)과 `snapshots/`(파일 사본)이다. 보고서가 모자라면 이걸 직접 읽는다.
