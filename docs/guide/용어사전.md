### 게임오브젝트 (GameObject)
**처음**: cp-02

씬 위에 놓이는 물건 하나하나. 새도 바닥도 카메라도 전부 게임오브젝트다.

> **비유** — 무대 위의 배우와 소품

⚠️ 게임오브젝트 자체는 **아무 능력도 없는 빈 껍데기**다. 능력은 전부 컴포넌트가 준다.

### 씬 (Scene)
**처음**: cp-02

게임의 한 화면을 담아두는 파일.

> **비유** — 연극의 무대 하나. 배우와 소품을 올려두고 그 상태를 통째로 저장한다

⚠️ 씬 탭 이름 옆에 별표(`*`)가 있으면 **아직 저장 안 된 것**이다.

### 좌표 (x, y, z)
**처음**: cp-02

위치를 숫자로 말하는 방법. **x** 가로(클수록 오른쪽) / **y** 세로(클수록 위) / **z** 깊이.

우리 게임은 옆에서 보는 2D 라 **z 는 계속 0** 이다.

⚠️ 1칸이 몇 cm 인지는 정해져 있지 않다. **우리가 정한다.** 이 게임은 새 한 마리가 1칸이다.

### 컴포넌트 (Component)
**처음**: cp-02

게임오브젝트에 붙이는 능력 하나. Transform, Mesh Renderer, Box Collider 등.

> **비유** — 배우에게 입히는 옷과 소품

**게임오브젝트 = 껍데기 + 컴포넌트 여러 개.** 이 문장이 Unity 의 거의 전부다.

### 화면 비율 (Aspect)
**처음**: cp-02

가로와 세로의 비율. 이 게임은 `16:9` 로 고정한다. Game 뷰 왼쪽 위 드롭다운에서 고른다.

Size 5 + 16:9 → 가로 절반 = 5 × (16÷9) = **8.889**

### Game 뷰 / Scene 뷰
**처음**: cp-02

| | 무엇인가 |
|---|---|
| **Scene 뷰** | 작업용 화면. 자유롭게 돌려보고 확대할 수 있다 |
| **Game 뷰** | **플레이어가 실제로 보게 될 화면** |

⚠️ 확인은 언제나 **Game 뷰 기준**이다. Scene 뷰에서 잘 보인다고 되는 게 아니다.

### Hierarchy 창
**처음**: cp-02

지금 씬에 있는 게임오브젝트 **목록**. 보통 왼쪽에 있다.
안 보이면 `Window > General > Hierarchy`

### Inspector 창
**처음**: cp-02

**선택한** 게임오브젝트의 컴포넌트와 값. 보통 오른쪽에 있다.

**Hierarchy 에서 클릭 → Inspector 에서 값을 고친다.** 이 흐름을 계속 반복한다.

### Orthographic / Perspective
**처음**: cp-02

카메라가 찍는 방식.

| | 뜻 | 특징 |
|---|---|---|
| **Perspective** | 사람 눈처럼 | 멀리 있는 게 작게 보인다 |
| **Orthographic** | 도면처럼 | **거리와 상관없이 같은 크기** |

이 게임은 옆에서 보는 2D 라 **Orthographic** 을 쓴다.

### Orthographic Size
**처음**: cp-02

화면에 세로로 몇 칸이 보일지. **위아래 절반의 칸 수**를 적는다.

**이 게임은 `5` 로 고정한다.** → 화면 세로 y = −5 ~ 5

⚠️ Size 는 세로만 정한다. 가로는 화면 비율에 따라 자동으로 정해진다.
⚠️ 값이 **작을수록 확대**된다. 물건이 커진 게 아니라 카메라가 당겨진 것이다.

### Transform
**처음**: cp-02

모든 게임오브젝트가 반드시 하나씩 갖고 있는 컴포넌트. `Position`(어디) / `Rotation`(얼마나 돌아갔나) / `Scale`(원래 크기의 몇 배).

⚠️ **지울 수 없다.** 위치가 없는 물건은 있을 수 없기 때문이다.
