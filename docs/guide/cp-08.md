## 알아야 할 것

### `if` — 조건에 따라 갈라지기

**"만약 ~라면 이걸 해라"** 는 뜻이다.

```csharp
if (조건)
{
    조건이 참일 때만 실행되는 코드
}
```

- 조건이 **참(true)** 이면 중괄호 안이 실행된다
- **거짓(false)** 이면 통째로 건너뛴다

> **비유** — 갈림길. 조건이 맞으면 들어가고, 아니면 지나친다.

지금까지 쓴 코드는 **무조건 실행**됐다. `if` 가 생기면서 **"어떤 때만"** 이 가능해진다.

⚠️ **`if` 뒤에는 세미콜론을 안 붙인다.**

```csharp
if (조건);      // 틀림 — 여기서 문장이 끝나버린다
{
}
```

### 입력 감지

**키보드가 눌렸는지 물어보는 것**이다.

```csharp
Input.GetKeyDown(KeyCode.Space)
```

- `Input` — 입력을 담당하는 Unity 기능
- `GetKeyDown` — "이 키가 **방금 눌렸나?**"
- `KeyCode.Space` — 스페이스바

이 문장은 **참 아니면 거짓**을 내놓는다. 그래서 `if` 의 조건 자리에 그대로 들어간다.

### `GetKeyDown` 과 `GetKey` 의 차이 ★

**이번 항목에서 가장 중요한 구분이다.**

| | 언제 참이 되나 | 스페이스를 3초간 꾹 누르면 |
|---|---|---|
| `GetKeyDown` | **누르는 순간 딱 한 번** | **1번** 참 |
| `GetKey` | **누르고 있는 동안 계속** | 약 **180번** 참 (매 프레임) |
| `GetKeyUp` | 떼는 순간 한 번 | 1번 참 |

> **비유** — `GetKeyDown` 은 **초인종**. 누르는 순간 한 번 울린다.
> `GetKey` 는 **손전등 버튼**. 누르고 있는 동안 계속 켜져 있다.

**우리는 `GetKeyDown` 을 쓴다.** 꾹 누르고 있다고 새가 계속 날아오르면 안 되기 때문이다.
그게 이번 체크의 **"꾹 눌러도 한 번만 튀어오른다"** 다.

### 점프에는 `Time.deltaTime` 을 곱하지 않는다 ★

07번에서 **"움직임에는 `deltaTime` 을 곱한다"** 고 배웠다. 그런데 점프에는 **안 곱한다.**

| | 어떤 일인가 | `deltaTime` |
|---|---|---|
| 낙하 | **계속** 일어나는 일 (매 프레임 조금씩) | **곱한다** |
| 점프 | **한 순간에** 일어나는 일 (눌렀을 때 한 번) | **안 곱한다** |

`deltaTime` 은 "이번 프레임이 걸린 시간" 이다. **시간에 걸쳐 일어나는 일**을 프레임 수와 무관하게 만들려고 곱하는 것이다.

점프는 이미 **"한 번" 만 일어난다.** 프레임 수와 무관하다. 여기에 `deltaTime`(0.017 같은 작은 수)을 곱하면 **거의 안 움직인다.**

⚠️ 07번을 배운 직후라 **모든 곳에 곱하고 싶어진다.** 기준은 하나다 — **"계속 일어나는 일인가, 한 번 일어나는 일인가?"**

---

## 해보기

### 1. 순서부터 세운다

이번에 할 일은 이것이다.

> **매 프레임 아래로 내려가되, 스페이스를 누른 순간에는 위로 튄다.**

한국어로 적어보자. **세 줄이면 된다.**

```
1. ________________________________
2. ________________________________
3. ________________________________
```

> 막히면 이 셋을 답해보자.
> - 내려가는 건 **계속** 하는 일인가, **어떤 때만** 하는 일인가?
> - 위로 튀는 건?
> - "어떤 때만" 을 코드로 만들려면 무엇이 필요한가?

### 2. 코드 고치기

```csharp
using UnityEngine;

public class BirdMove : MonoBehaviour
{
    public float fallSpeed = 3f;
    public float jumpPower = ________;

    void Update()
    {
        transform.position += new Vector3(0f, -fallSpeed * Time.deltaTime, 0f);

        ____ (________________________________)
        {
            transform.position += new Vector3(0f, ________, 0f);
        }
    }
}
```

**빈칸 힌트**

| 빈칸 | 힌트 |
|---|---|
| `jumpPower` 값 | **한 번에 몇 칸** 올라갈까. 낙하가 초당 3칸이니 그 절반쯤이 적당하다 |
| 조건 앞 | 조건에 따라 갈라지게 하는 말 |
| 조건 안 | `Input.` 으로 시작한다. **누른 순간**을 감지하는 것 |
| `Vector3` 두 번째 칸 | 위로 가야 한다. **부호**와, **`deltaTime` 을 곱할지 말지** 생각하자 |

### 3. 저장하고 Play

`Ctrl + S` → Unity → **Play** → **스페이스를 연타**해보자.

> **Game 뷰를 한 번 클릭해두자.** 다른 창이 선택돼 있으면 키 입력이 게임으로 안 간다.

## 확인하기

- [ ] 스페이스를 누르면 새가 **위로 튄다**
- [ ] 연타하면 새가 **화면 안에 떠 있다** (5초 이상)
- [ ] 스페이스를 **꾹 누르고 있어도 한 번만** 튀어오른다
- [ ] Inspector 에 `Jump Power` 칸이 보인다

### 꾹 눌러보기

**스페이스를 3초간 꾹 눌러보자.** 한 번만 튀어오르고 그 뒤로는 계속 내려가야 한다.

계속 날아오른다면 `GetKey` 를 쓴 것이다. `GetKeyDown` 으로 바꾸자.

## 안 되면

### 스페이스를 눌러도 아무 반응이 없다

**원인 1 — 가장 흔하다.** **Game 뷰가 선택돼 있지 않다.**
키 입력은 **지금 선택된 창**으로 간다. Game 뷰를 한 번 클릭하고 다시 눌러보자.

**원인 2** — 아래 에러가 났다.

```
InvalidOperationException: You are trying to read Input using the UnityEngine.Input class,
but you have switched active Input handling to Input System package in Player Settings.
```

**Unity 가 구식 입력 기능을 꺼둔 것이다.** 이 교재의 프로젝트는 처음부터 켜뒀지만, 새 프로젝트를 만들었다면 이 에러가 난다.

**고치는 법**
1. `Edit > Project Settings > Player`
2. `Other Settings` 를 펼친다
3. `Active Input Handling` 을 **`Both`** 로 바꾼다
4. **Unity 를 껐다 켠다** ← 재시작해야 적용된다

**원인 3** — 컴파일 에러. Console 의 빨간 줄부터.

### 꾹 누르면 계속 날아오른다

**원인** — `GetKey` 를 썼다. `GetKeyDown` 으로 바꾸자.

| | 꾹 누를 때 |
|---|---|
| `GetKey` | 매 프레임 참 → 계속 날아오른다 |
| `GetKeyDown` | 누른 순간만 참 → 한 번만 |

### 스페이스를 눌러도 거의 안 움직인다

**원인** — 점프에 `Time.deltaTime` 을 곱했다.

```csharp
transform.position += new Vector3(0f, jumpPower * Time.deltaTime, 0f);   // 거의 안 움직인다
transform.position += new Vector3(0f, jumpPower, 0f);                    // 정상
```

`deltaTime` 은 0.017 정도로 아주 작다. 1.5칸 올라가야 하는데 0.025칸만 올라간다.

**점프는 "한 번" 일어나는 일이라 곱하지 않는다.**

### 새가 하늘로 날아가버린다

**원인 1** — `if` 뒤에 세미콜론을 붙였다.

```csharp
if (Input.GetKeyDown(KeyCode.Space));   // ← 이 세미콜론
{
    transform.position += new Vector3(0f, jumpPower, 0f);
}
```

세미콜론이 붙으면 **`if` 가 거기서 끝나고**, 아래 중괄호는 조건과 상관없이 **매 프레임 실행된다.**

⚠️ **컴파일 에러가 안 난다.** 문법상 맞는 코드라서 Unity 는 아무 말도 안 한다. 화면을 봐야 안다.

**원인 2** — `jumpPower` 가 너무 크다. Inspector 에서 줄여보자.

### 연타해도 자꾸 떨어진다

**낙하 속도에 비해 점프가 약한 것이다.** 균형을 맞춰보자.

```
초당 낙하 3칸 ÷ 한 번에 1.5칸 = 초당 2번 눌러야 제자리
```

Inspector 에서 `Jump Power` 를 올리거나 `Fall Speed` 를 내려보자. **값을 만지는 건 07번에서 배운 것이다.**

## 그래도 안 되면 — 답

> 「순서부터 세운다」를 스스로 해봤다면 봐도 된다.

**순서 예시**

1. 매 프레임 아래로 내려간다 (계속 하는 일)
2. 스페이스를 **누른 순간**인지 확인한다 (어떤 때만)
3. 눌렸으면 위로 한 번 튄다

**완성 코드** — `Assets/Scripts/BirdMove.cs`

```csharp
using UnityEngine;

public class BirdMove : MonoBehaviour
{
    public float fallSpeed = 3f;
    public float jumpPower = 1.5f;

    void Update()
    {
        transform.position += new Vector3(0f, -fallSpeed * Time.deltaTime, 0f);

        if (Input.GetKeyDown(KeyCode.Space))
        {
            transform.position += new Vector3(0f, jumpPower, 0f);
        }
    }
}
```

**07번에서 뭐가 바뀌었나**

```diff
     public float fallSpeed = 3f;
+    public float jumpPower = 1.5f;
 
     void Update()
     {
         transform.position += new Vector3(0f, -fallSpeed * Time.deltaTime, 0f);
+
+        if (Input.GetKeyDown(KeyCode.Space))
+        {
+            transform.position += new Vector3(0f, jumpPower, 0f);
+        }
     }
```

**두 줄의 차이를 보자**

```csharp
transform.position += new Vector3(0f, -fallSpeed * Time.deltaTime, 0f);   // 계속 → deltaTime 곱함, 아래로(-)
transform.position += new Vector3(0f,  jumpPower,                 0f);   // 한 번 → 안 곱함,      위로(+)
```

## 더 알고 싶으면

### 얼마나 빨리 눌러야 제자리인가

이 교재를 만들면서 **자동으로 연타시켜** 재본 값이다.

```
0.48초마다 1번씩 누름 (초당 약 2.05회)
12.67초 동안 26번 눌렀을 때
새의 y 위치: -1.00 ~ 1.72 사이에서 오르내림 → 화면 밖으로 안 나감
```

계산해보면 이렇다.

```
내려가는 속도 = 초당 3칸
올라가는 양   = 한 번에 1.5칸

초당 2번 누르면 = 초당 3칸 올라감  →  딱 상쇄된다
```

**초당 2번보다 빨리 누르면 올라가고, 느리면 내려간다.** 이 균형이 게임의 난이도가 된다.
24번에서 이 값들을 다시 조절한다.

### 진짜 점프처럼 안 보이는데

맞다. 지금은 **순간이동**이다. 눌렀을 때 즉시 1.5칸 위로 순간이동하고, 그 뒤로 일정한 속도로 내려간다.

진짜 점프는 **올라가다가 점점 느려지고, 멈췄다가, 점점 빨라지며 떨어진다.**

**18번에서 진짜 물리로 바꾼다.** 그때 이 코드는 통째로 사라진다. 지금 어색한 건 정상이다.
