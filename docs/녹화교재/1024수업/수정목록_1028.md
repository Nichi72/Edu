### F. 기획서가 교재의 뼈대가 된다

### G. 코드가 바뀐 곳을 한눈에

- 같은 코드의 전과 후를 블록 두 개로 따로 두지 않는다. **한 블록 안에서** 바뀐 곳을 표시한다
  - 새로 생긴 줄 — 초록 바탕
  - 지운 줄 — 빨강 취소선
  - 줄 안에서 바뀐 칸 — 그 칸만 강조 (`5` → `speed`)
- 해당하는 곳
  - ch02: 하드코딩 `5` → `speed`, `public` 붙이기, 점프 줄 넣기
  - ch03: `Translate` 지우고 `linearVelocity`, `GetComponent` 줄 주석 처리
- 빌드 도구에 표시 문법을 더한다. 예: 줄 앞 `+` `-`, 줄 안 `{-5-}{+speed+}`

```text
    }
```
