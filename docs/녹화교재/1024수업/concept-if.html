개념 정리

if — 조건에 따라 할지 말지 정한다

02 에서 점프를 만들려고 if 를 썼다. 여기서는 if 를 조금 더 깊게 본다. 02 를 끝내는 데 꼭 필요하지는 않다. 조건문은 「프로그래밍의 절반」 이라고 할 만큼 자주 쓴다. 한 번 제대로 보고 가면 뒤에서 덜 막힌다.

1

if 의 모양

BirdMove.csAssets/Script
if(조건)
{
    // 조건이 true 일 때만 하는 일
}

괄호 안이 true 면 중괄호 안으로 들어가고, false 면 통째로 건너뛴다.

Update 안에 쓴 if 는 매 프레임 다시 묻는다. 02 의 점프가 그랬다. 1초에 수십 번 「눌렀니?」 하고 묻고, 누른 그 프레임에만 들어간다.

2

조건 자리에 들어가는 것 — bool

조건 자리에는 참 아니면 거짓, 둘 중 하나인 값이 들어간다. 이런 값을 bool 이라고 한다. 변수 기본형 넷 int float char bool 중 하나다.

조건 자리에 쓴 것예
값 그대로if(true) — 항상 들어간다
bool 변수if(isBool)
bool 을 돌려주는 것if(Keyboard.current.spaceKey.wasPressedThisFrame)
비교if(transform.position.y < -4)

마지막 줄처럼 두 값을 비교하면 bool 이 나온다. 새의 높이가 −4 보다 작으면 true 다. 기획서의 「땅에 닿으면 게임 오버」 를 만들 때 이런 조건을 쓰게 된다.

비교뜻speed 가 5 일 때
speed > 3크다true
speed < 3작다false
speed >= 5크거나 같다true
speed <= 4작거나 같다false
speed == 5같다true
speed != 5다르다false
3

직접 켜고 꺼 보기

조건을 Inspector 의 체크 상자로 만들어 Play 중에 켜고 꺼 본다.

BirdMove.csAssets/Script
    public bool isBool = true;

    void Update()
    {
        if(isBool)
        {
            Debug.Log("참입니다.");
        }
    }

▶ Play Console 에 「참입니다.」 가 계속 찍힌다. Play 중에 Inspector 의 Is Bool 체크를 끈다. 더 안 찍힌다. 다시 켜면 다시 찍힌다.

4

else — 아니면

if 가 아닐 때 할 일은 else 에 쓴다.

BirdMove.csAssets/Script
        if(isBool)
        {
            Debug.Log("참입니다.");
        }
        else
        {
            Debug.Log("거짓입니다.");
        }

이제 Is Bool 을 끄면 「거짓입니다.」 가 찍힌다. 둘 중 하나는 반드시 실행된다.

5

else if — 여러 갈래

갈래가 셋 이상이면 else if 를 잇는다.

BirdMove.csAssets/Script
        if(speed > 10)
        {
            Debug.Log("너무 빠르다");
        }
        else if(speed > 3)
        {
            Debug.Log("알맞다");
        }
        else
        {
            Debug.Log("너무 느리다");
        }

위에서부터 차례로 묻고, 처음 true 인 곳 하나만 실행한다. speed 가 12 면 「너무 빠르다」 만 찍힌다. speed > 3 도 참이지만 거기까지 묻지 않는다. 그래서 순서가 중요하다.

멈춤speed 가 5 면 무엇이 찍히나? 3 이면?

5 면 「알맞다」. 3 이면 「너무 느리다」. 3 > 3 은 false 이기 때문이다.

6

자주 틀리는 것

  • if(조건); 괄호 뒤에 세미콜론. if 가 거기서 끝나 버린다. 중괄호 안은 조건과 상관없이 항상 실행된다. 빨간 줄이 안 생겨서 찾기 어렵다.
  • = 와 ==. if(speed = 5) 는 빨간 줄이 생긴다. = 는 「넣어라」, == 는 「같은지 물어라」 다.
  • 중괄호를 뺐다. 중괄호가 없으면 if 바로 아래 한 줄만 if 에 속한다. 둘째 줄부터는 항상 실행된다. 한 줄이어도 중괄호를 쓰는 버릇을 들인다.
