Chapter 05

스코어 — 파이프의 사이를 지나면

이번 시간에 만드는 것

Play 를 누르면 이렇게 된다.

  • 1새가 파이프 사이를 빠져나가면 점수가 1 오른다
  • 2파이프 사이에는 보이지 않는 칸이 있다. 새는 그 칸에 막히지 않는다
  • 3파이프가 세 쌍이다. 다 지나가면 점수가 3 이다. 점수는 Inspector 와 Console 에서 본다

이번에 배우는 말 — Is Trigger · OnTriggerEnter · int

이번에 정해지는 이름이다. 철자와 대소문자까지 이대로 쓴다.

5.1

시작하기 전에

04 를 끝냈다. 땅이나 파이프에 닿으면 Console 에 게임 오버 가 찍히고 게임이 멈춘다
5.2

파이프의 사이를 지나면 점수가 1점씩 오른다

기획서스코어
  1. ▶1. 파이프의 사이를 지나면 점수가 1점씩 오른다

새가 파이프 사이를 지나가면 점수가 1 오르게 만든다. 지금은 지나가도 아무 일이 없다.

이걸 하려면 세 가지가 필요하다.

  1. 「지나갔다」 를 알아챌 칸
  2. 그 칸에 들어간 순간 을 코드가 아는 방법
  3. 점수를 세는 변수

필요한 것 1 — 지나간 걸 알아챌 칸

두 파이프 사이 틈에 칸을 하나 놓는다.

  1. 3D Object > Cube → 이름 ScoreZone
  2. 틈을 꽉 채우게 놓는다
이름PositionScale
ScoreZone4, 0.5, 01, 3, 1

▶ Play 틈으로 날아가 본다. 게임 오버가 된다.

멈춤왜 게임 오버일까?

ScoreZone 도 Cube 라서 Box Collider 가 있다. 새에게는 벽이다. 04 의 OnCollisionEnter 가 불렸다.

벽이 아니라 지나가게 만든다. ScoreZone 의 Box Collider 에서 Is Trigger 를 체크한다.

▶ Play 새가 ScoreZone 을 그냥 통과한다. 게임 오버도 없다.

Is Trigger체크하면 Collider 가 막지 않고, 지나가는 것만 알아챈다. 달리기의 결승선과 같다. 선은 아무도 막지 않지만, 누가 지나갔는지는 안다.

이제 ScoreZone 이 보일 필요는 없다. ScoreZone 의 Mesh Renderer 체크를 끈다. 04 에서 본 대로 보이는 것과 부딪히는 것은 따로다. Game 뷰에서는 사라지고, Scene 뷰에서 선택하면 초록 선이 남는다.

필요한 것 2 — 칸에 들어간 순간

멈춤새가 ScoreZone 을 지날 때 04 의 OnCollisionEnter 가 불릴까?

안 불린다. 그래서 게임 오버도 없었다. Trigger 를 지날 때는 다른 함수가 불린다. BirdMoveByRid 의 OnCollisionEnter 아래에 쓴다.

BirdMoveByRid.csAssets/Script
    void OnTriggerEnter(Collider other)
    {
        Debug.Log("통과");
    }

▶ Play 틈을 지나는 순간 Console 에 통과 가 찍힌다.

OnTriggerEnterTrigger 칸에 들어간 순간 Unity 가 한 번 부르는 함수. 괄호 안 other 에는 새가 들어간 칸(ScoreZone)의 Collider 가 들어온다.

04 와 나란히 놓으면 이렇다.

ScoreZone 의 Is Trigger새는Unity 가 부르는 함수
끔 — 벽막힌다OnCollisionEnter(Collision collision)
켬 — 결승선지나간다OnTriggerEnter(Collider other)

괄호 안도 다르다. Collision 과 Collider. 바꿔 쓰면 Console 에 에러가 뜨고 함수가 불리지 않는다.

필요한 것 3 — 점수 세기

통과 대신 점수가 올라가야 한다. 점수를 담을 변수를 만든다.

바꾸기 전BirdMoveByRid.cs
public float jumpPower = 10;
바꾼 뒤BirdMoveByRid.cs
public float jumpPower = 10;
public int score = 0;
int소수점 없는 수를 담는 변수 타입. 점수 · 목숨 · 개수처럼 셀 수 있는 것에 쓴다. 속도처럼 0.5 가 될 수 있는 것은 float 이다.
바꾸기 전BirdMoveByRid.cs
Debug.Log("통과");
바꾼 뒤BirdMoveByRid.cs
score = score + 1;
Debug.Log(score);
멈춤score = score + 1 은 수학으로 보면 말이 안 된다. 무슨 뜻일까?

오른쪽을 먼저 계산해서 왼쪽에 넣는다. 지금 점수에 1 을 더해 다시 점수에 넣는다. = 는 「같다」 가 아니라 「넣는다」 다.

▶ Play Bird 를 선택해 두고 Inspector 의 Score 칸을 보면서 틈을 지나간다. 지날 때마다 1 씩 오른다. Console 에도 찍힌다.

「1점씩 오른다」 를 보려면 파이프가 더 있어야 한다.

  1. Hierarchy 에서 PipeTop · PipeBottom · ScoreZone 을 Ctrl 을 누른 채 함께 선택
  2. Ctrl + D 로 복사 → 복사된 셋을 Scene 뷰에서 오른쪽으로 끌어 옮긴다
  3. 한 번 더

▶ Play 세 쌍을 다 지나가면 Score 가 3 이다.

다음 시간 질문점수가 Inspector 와 Console 에만 있다. 플레이어는 Game 뷰만 본다. 점수를 게임 화면에 띄우려면?
5.3

확인하기

ScoreZone 의 Is Trigger 는 켜져 있고, Mesh Renderer 는 꺼져 있다
틈을 지나가면 막히지 않고 Score 가 1 오른다
파이프나 땅에 닿으면 04 처럼 게임이 멈춘다
Is Trigger 를 켜면 왜 OnCollisionEnter 대신 OnTriggerEnter 가 불리는지 말할 수 있다
5.4

안 되면

  • 틈에서 게임 오버가 된다 → ScoreZone 의 Is Trigger 를 안 켰다.
  • 새가 땅을 뚫고 떨어진다 → Is Trigger 를 Bird 에 켰다. Bird 에서 끄고 ScoreZone 에 켠다.
  • 지나가도 아무것도 안 찍힌다 → 함수 이름의 철자. 04 와 같다. OnTriggerEnter(Collider other)
  • Console 에 This message parameter has to be of type 에러 → 괄호 안 타입이 바뀌었다. OnTriggerEnter 는 Collider, OnCollisionEnter 는 Collision.
5.5

답 — 이 시간이 끝났을 때의 코드

여기까지 스스로 해봤다면 봐도 된다.

BirdMoveByRid.csAssets/Script
using UnityEngine;
using UnityEngine.InputSystem;

public class BirdMoveByRid : MonoBehaviour
{
    public Rigidbody rb;
    public float forwardSpeed = 5;
    public float jumpPower = 10;
    public int score = 0;

    void Start()
    {
        // rb = GetComponent<Rigidbody>();

        // 오른쪽으로움직이는 코드
        rb.linearVelocity = new Vector3(forwardSpeed,0,0);
    }

    // Update is called once per frame
    void Update()
    {
        // 3. 스페이스를 통해 점프
        // 위 방향으로 스페이스를 눌렀을때 점프를 한다.

        if(Keyboard.current.spaceKey.wasPressedThisFrame) // 스페이스를 눌렀을때
        {
            //위 방향으로 점프를 한다.
            rb.linearVelocity = new Vector3(forwardSpeed,jumpPower,0);
        }
    }

    // 게임오버 조건 — 파이프에 닿으면, 땅에 닿으면
    void OnCollisionEnter(Collision collision)
    {
        Debug.Log("게임 오버");
        Time.timeScale = 0;
    }

    // 스코어 — 파이프의 사이를 지나면 점수가 1점씩 오른다
    void OnTriggerEnter(Collider other)
    {
        score = score + 1;
        Debug.Log(score);
    }
}

씬 — 파이프 세 쌍. 쌍마다 ScoreZone 이 틈에 있고, Is Trigger 켬 · Mesh Renderer 끔.
