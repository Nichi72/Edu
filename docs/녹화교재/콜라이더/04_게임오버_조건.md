> **이번 시간에 만드는 것** — Play 를 누르면 이렇게 된다.
> 1. 새가 땅에 닿으면 게임이 그 자리에서 멈춘다
> 2. 새 앞에 파이프 한 쌍이 있다. 파이프에 닿아도 게임이 멈춘다
> 3. 멈출 때 Console 에 「게임 오버」 가 찍힌다

**이번에 배우는 말** — [Collider](#s2) · [OnCollisionEnter](#s2) · [Time.timeScale](#s2)

이번에 정해지는 이름이다. ==철자와 대소문자까지 이대로 쓴다.==

| 이름 | 무엇 | 값 |
|---|---|---|
| `OnCollisionEnter` | 부딪힌 순간 Unity 가 부르는 함수. 우리가 지은 이름이 아니다 | — |
| `PipeTop` | 위쪽 파이프. Cube | — |
| `PipeBottom` | 아래쪽 파이프. Cube | — |

## 땅에 닿으면 게임 오버

```기획서
게임오버 조건
· 1. 파이프에 닿으면 게임 오버
▶ 2. 땅에 닿으면 게임 오버
```

==새가 땅에 닿으면 게임이 멈추게 만든다.== 지금은 땅에 내려앉아 미끄러진다. 땅은 이미 씬에 있으니 2 부터 한다.

이걸 하려면 세 가지가 필요하다.

1. 새와 땅이 **부딪히는** 것
2. 부딪힌 **그 순간** 을 코드가 아는 방법
3. 게임을 **멈추는** 방법

### 필요한 것 1 — 부딪히기

> 멈춤 — 새는 왜 땅을 뚫고 떨어지지 않을까? 「땅에서 멈춰라」 라는 코드는 쓴 적이 없다.

해 본다.

1. Hierarchy 에서 `Bird` 클릭
2. Inspector 의 **Box Collider** 이름 옆 체크를 끈다
3. **Play.** ==새가 땅을 뚫고 떨어진다.==
4. Play 를 멈추고 체크를 다시 켠다

> **Collider** — ==부딪히는 범위를 정하는 컴포넌트.== Rigidbody 가 움직임을 맡는다면 Collider 는 모양을 맡는다. Cube 를 만들 때 Box Collider 가 이미 붙어 있었다. Ground 에도 있다.

Scene 뷰에서 `Bird` 를 선택하면 큐브 둘레에 초록 선이 보인다. 그게 Collider 의 범위다.

이번엔 반대로 해 본다. `Bird` 의 **Mesh Renderer** 체크를 끄고 **Play.** Game 뷰에서 새가 사라진다. 그런데 Scene 뷰의 초록 선은 여전히 땅 위에 선다. ==보이는 것(Mesh Renderer)과 부딪히는 것(Collider)은 따로다.== 확인했으면 다시 켠다.

모양은 Box 말고도 있다. 공은 Sphere Collider, 길쭉한 캡슐은 Capsule Collider. 새는 큐브니까 Box Collider 그대로 둔다. 더 보려면 [충돌 정리](concept-collider.html).

### 필요한 것 2 — 부딪힌 그 순간

부딪히는 건 이미 된다. 이제 ==부딪힌 순간에 코드가 실행되게 한다.== `BirdMoveByRid` 를 열고 `Update` 아래에 쓴다.

```csharp
    void OnCollisionEnter(Collision collision)
    {
        Debug.Log("게임 오버");
    }
```

**Play.** 새가 땅에 닿는 순간 Console 에 `게임 오버` 가 찍힌다.

> 멈춤 — 이 함수를 부르는 줄을 우리가 쓴 적이 있나?

==없다. Unity 가 부딪힌 순간에 불러 준다.== `Start` 와 `Update` 를 우리가 부르지 않았던 것과 같다.

> **OnCollisionEnter** — 다른 Collider 와 ==부딪힌 순간 Unity 가 한 번 부르는 함수.== 괄호 안 `collision` 에는 무엇과 부딪혔는지가 들어온다. 이번엔 쓰지 않는다.

==이름이 한 글자라도 다르면 에러 없이 그냥 안 불린다.== `OnColisionEnter`(l 하나), `onCollisionEnter`(소문자 o) 모두 안 된다. 01 의 대소문자 이야기가 여기서 그대로 나온다.

닿아 있는 동안 계속 불리는 `OnCollisionStay`, 떨어질 때 불리는 `OnCollisionExit` 도 있다. 게임 오버는 닿는 순간 한 번이면 되니 `Enter` 만 쓴다.

### 필요한 것 3 — 게임 멈추기

Console 에 찍히기만 하고 새는 계속 미끄러진다. ==진짜로 멈춰야 게임 오버다.==

```csharp 전
        Debug.Log("게임 오버");
```
```csharp 후
        Debug.Log("게임 오버");
        Time.timeScale = 0;
```

**Play.** ==땅에 닿는 순간 모든 게 그 자리에 선다.==

> **Time.timeScale** — 게임 시간이 흐르는 빠르기. 1 이 보통, 0.5 면 슬로모션, ==0 이면 멈춘다.== 지금은 「멈추는 줄이 있다」 정도만 알면 된다.

## 파이프에 닿으면 게임 오버

```기획서
게임오버 조건
▶ 1. 파이프에 닿으면 게임 오버
✓ 2. 땅에 닿으면 게임 오버
```

==새가 파이프에 닿아도 게임이 멈추게 만든다.== 그러려면 먼저 파이프가 있어야 한다.

파이프는 큐브 두 개다. 지금은 손으로 한 쌍만 놓는다. 여러 개를 만드는 건 파이프 시간에 한다.

1. Hierarchy 빈 곳 오른쪽 클릭 → **3D Object > Cube** → 이름 `PipeTop`
2. 하나 더 → 이름 `PipeBottom`
3. Inspector 의 Transform 을 아래처럼 맞춘다. ==가운데에 새가 지나갈 틈이 남는다.==

| 이름 | Position | Scale |
|---|---|---|
| `PipeTop` | 4, 4, 0 | 1, 4, 1 |
| `PipeBottom` | 4, -2.5, 0 | 1, 3, 1 |

**Play.** 점프로 버티다가 파이프에 일부러 부딪혀 본다. ==코드를 한 줄도 안 더했는데 게임 오버가 된다.==

> 멈춤 — 왜 될까? 아까는 땅만 생각하고 썼다.

==`OnCollisionEnter` 는 무엇과 부딪혀도 불린다.== 땅이든 파이프든. 그리고 Cube 에는 Box Collider 가 이미 있다. 기획서 두 줄이 코드 하나로 끝났다.

> 멈춤 — 파이프에는 Rigidbody 가 없다. 그래도 왜 부딪힘을 알까?

> **한 가지 더** — 부딪힘을 알려면 ==부딪히는 둘 중 하나에만 Rigidbody 가 있으면 된다.== 움직이는 쪽(새)에 붙인다. 파이프에 붙이면 파이프가 중력을 받아 떨어진다.

> **다음 시간 질문** — 기획서의 스코어는 「파이프의 사이를 지나면 점수가 1점씩 오른다」 다. 그런데 파이프는 닿으면 게임 오버다. 사이를 **지나갔다** 는 건 어떻게 알까?

## 확인하기

- [ ] Bird 의 Box Collider 를 끄면 땅을 뚫고, 켜면 땅에 선다
- [ ] 땅에 닿으면 Console 에 `게임 오버` 가 찍히고 모든 게 멈춘다
- [ ] 파이프에 닿아도 똑같다. 코드는 더 쓰지 않았다
- [ ] 파이프에는 Rigidbody 가 없다

## 안 되면

- **닿아도 Console 에 아무것도 안 찍힌다** → ==함수 이름의 철자나 대소문자가 틀렸다.== 에러가 안 나니 한 글자씩 맞춰 본다. `OnCollisionEnter(Collision collision)`
- **파이프가 아래로 떨어진다** → ==파이프에 Rigidbody 를 붙였다.== 지운다.
- **새가 땅을 뚫고 떨어진다** → Bird 의 Box Collider 가 꺼져 있다. 필요한 것 1 에서 끄고 다시 안 켰다.
- **Game 뷰에 파이프가 안 보인다** → 카메라는 새를 따라가지 않는다. Position 을 표대로 넣었는지 본다.

## 답 — 이 시간이 끝났을 때의 코드

여기까지 스스로 해봤다면 봐도 된다.

```csharp
using UnityEngine;
using UnityEngine.InputSystem;

public class BirdMoveByRid : MonoBehaviour
{
    public Rigidbody rb;
    public float forwardSpeed = 5;
    public float jumpPower = 10;

    void Start()
    {
        // rb = GetComponent<Rigidbody>();

        // 오른쪽으로움직이는 코드
        rb.linearVelocity = new Vector3(forwardSpeed,0,0);
    }

    // Update is called once per frame
    void Update()
    {
        // 3. 스페이스를 통해 점프
        // 위 방향으로 스페이스를 눌렀을때 점프를 한다.

        if(Keyboard.current.spaceKey.wasPressedThisFrame) // 스페이스를 눌렀을때
        {
            //위 방향으로 점프를 한다.
            rb.linearVelocity = new Vector3(forwardSpeed,jumpPower,0);
        }
    }

    // 게임오버 조건 — 파이프에 닿으면, 땅에 닿으면
    void OnCollisionEnter(Collision collision)
    {
        Debug.Log("게임 오버");
        Time.timeScale = 0;
    }
}
```

씬 — `PipeTop` · `PipeBottom` 이 새 오른쪽에 있다. 둘 다 Box Collider 만 있고 Rigidbody 는 없다.
